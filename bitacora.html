📓 Bitácora del Equipo

Decisiones

  • Elegimos el nombre TechArg para el equipo.
  • Decidimos usar una paleta oscura con acentos azules.
  • Cada integrante tendría su propio CSS para no mezclar estilos.
  • La portada tendría un carrusel con las tarjetas de cada perfil.

Dificultades

  • Coordinar los horarios de reunión del grupo.
  • Organizar las carpetas de imágenes para que no se mezclen.
  • Resolver conflictos de Git al mergear las ramas.

Cambios

  • Separamos las imágenes por integrante en subcarpetas.
  • Agregamos funciones dinámicas extra en cada perfil.
  • Mejoramos el diseño de las tarjetas con hover y transiciones.
