📓 Bitácora del Equipo

🎯 Decisiones de Diseño

  • Elegimos el nombre TechArg porque combina "Tech" (tecnología) con "Arg" (Argentina), representando nuestra identidad y el origen del equipo.
  • Definimos una paleta de colores oscura con acentos azules y violetas, ya que transmite profesionalismo y modernidad, y es agradable a la vista en pantallas de larga exposición.
  • Decidimos que cada integrante tuviera su propio archivo CSS (mariana.css, miguel.css, etc.) para evitar conflictos de estilos y permitir personalización individual dentro de una misma línea visual.
  • La portada tendría un carrusel de habilidades y una grilla con las tarjetas de cada integrante, para mostrar la información de manera ordenada y accesible.
  • Usamos Google Fonts (Roboto y Rubik) para lograr una tipografía clara y consistente en todo el sitio.

⚠️ Dificultades y Soluciones

  • Coordinar horarios: al ser un equipo distribuido, nos costó coincidir para las reuniones. Lo resolvimos usando Discord y mensajes asincrónicos, y dividiendo las tareas en partes independientes.
  • Conflictos de Git: al mergear las ramas individuales, aparecieron conflictos en el README.md y en el index.html. Los resolvimos desde GitHub con el botón "Resolve conflicts" y elegimos la versión más completa.
  • Organización de imágenes: al principio todas las imágenes estaban mezcladas en la carpeta img/. Creamos subcarpetas por integrante (img/miguel/, img/sergio/, etc.) para evitar confusiones.
  • Unificación del header y footer: cada integrante había hecho su propio header y footer. Tuvimos que unificarlos para que la navegación fuera consistente en todas las páginas.
  • Permisos en Windows: Git nos daba errores de "Permission denied" al mergear. Lo solucionamos cerrando VS Code y el navegador antes de ejecutar git merge.

🔄 Cambios y Mejoras

  • Separamos las imágenes por integrante en subcarpetas para mejorar la organización del repositorio.
  • Agregamos funciones dinámicas propias en cada perfil: reloj en tiempo real, filtro de habilidades, recomendador al azar, efecto 3D, etc.
  • Mejoramos el diseño de las tarjetas con hover, transiciones y animaciones para una experiencia más fluida.
  • Reemplazamos el carrusel de tarjetas por una grilla de equipo y un carrusel de habilidades, para mostrar mejor los contenidos.
  • Unificamos el header y el footer en todas las páginas, incluyendo el menú hamburguesa y el dropdown de perfiles.

📚 Aprendizajes

  • Aprendimos a trabajar con Git y GitHub de forma colaborativa: ramas, merges, pull requests y resolución de conflictos.
  • Entendimos la importancia de la organización de archivos (CSS, JS, imágenes) para mantener un proyecto mantenible.
  • Practicamos HTML semántico, CSS avanzado (Flexbox, Grid, animaciones) y JavaScript interactivo (DOM, eventos, localStorage).
  • Descubrimos el valor de la comunicación constante y la división clara de tareas en un equipo distribuido.
  • Incorporamos herramientas de IA como asistentes técnicos, siempre revisando y adaptando el código con criterio propio.
